# 반도체 센서 데이터로 불량 여부 예측하기

SECOM 센서 측정값 CSV를 올리면, 데이터 훑기 → 전처리 → 학습 → 결과 → 리포트까지 한 화면에서 확인할 수 있는 Streamlit 앱입니다.

## 실행 방법

```
pip install -r requirements.txt
streamlit run app.py
```

## 탭 구성

1. **데이터 훑기** — CSV 업로드, 행/열 수, 빈칸 개수, 결과 열 분포 확인
2. **전처리** — 빈칸 채우기, 글자 열 처리, 결과 열 0/1 변환, 학습·시험용 분리
3. **학습** — 표준화 후 로지스틱 회귀 학습
4. **결과** — 기준 모델과 나란히 비교(정확도·정밀도·재현율·F1), 혼동행렬
5. **리포트** — 전체 과정 요약
